# 🗺️ ROADMAP — AI Message Aggregator & Buffer System

Документ отражает текущий статус системы, завершенные этапы и план развития на будущие релизы.

---

## 📊 Текущий статус: Версия v2.6 (Stable)

Система полностью функциональна и готова к промышленной эксплуатации на Linux VPS и локальных машинах.

- [x] **Мультиканальный сбор:**
  - [x] ВКонтакте (VK LongPoll API) — ЛС и сообщества.
  - [x] Email / Mail.ru (IMAP) — чтение, парсинг тем, адресов и тела.
  - [x] Публичные Telegram-каналы — парсинг без использования пользовательских сессий/MTProto.
- [x] **Нейросетевой фильтр (Gemini AI Engine):**
  - [x] Классификация по 11 категориям контента.
  - [x] Каскадный fallback по 5 моделям (Lite -> Flash) при исчерпании лимитов 429.
  - [x] Батч-обработка сообщений (экономия до 80% токенов).
  - [x] Мультимодальная транскрипция голосовых заметок.
  - [x] Встроенный SmartDNS резолвер (Comss / Xbox) для обхода региональных блокировок Google API.
- [x] **Telegram UI & Доставка:**
  - [x] Два режима доставки: Instant (мгновенно) и Digest (сводка с интервалами 15м/30м/1ч/2ч/4ч).
  - [x] Ночной режим ("Часы тишины"): накопление сообщений в буфере до утра.
  - [x] Дифференцированное автоудаление сервисных сообщений и списков.
  - [x] «Умные подсказки» в чате бота с автоматической очисткой.
- [x] **ИИ-Ассистент:**
  - [x] 19 Function Calling инструментов для управления всеми параметрами бота на естественном языке.
  - [x] Интеграция с живым веб-поиском DuckDuckGo.
- [x] **Инфраструктура и надежность:**
  - [x] SQLite в режиме WAL с индексацией и дедупликацией `msg_uid`.
  - [x] 32 автоматических теста (юнит + интеграционные).
  - [x] Скрипты деплоя под systemd (`deploy.sh`, `update.sh`) и Docker-контейнеры.

## 🔮 Версия v3.0 — Новые платформы и RAG-поиск (Q2-Q3 2027)

Цель релиза: превращение агрегатора в универсальный хаб сообщений с интеллектуальным архивом.

- [ ] **Новые адаптеры источников:**
  - [ ] **WhatsApp** (через Baileys / WhatsApp Web API шлюз).
  - [ ] **Discord** (сбор сообщений из указанных серверов и каналов через Discord Bot API).
  - [ ] **Авито / Маркетплейсы** (прямая интеграция через API уведомлений продавца).
  - [ ] **Входящие вебхуки (Custom Webhooks):** Generic HTTP-эндпоинт для приема сообщений из CRM или личных сервисов.
- [ ] **Векторный поиск по истории (RAG / Semantic Search):**
  - [ ] Локальный векторный индекс (`sqlite-vec` или легковесный ChromaDB).
  - [ ] Поиск в чате бота на естественном языке: *«Найди письмо от бухгалтерии за прошлый месяц про акт»*.
- [ ] **Локальные модели (Local LLMs):**
  - [ ] Поддержка Ollama / vLLM для полной автономности и конфиденциальности без облачных API.
  - [ ] Автоматическое переключение на локальную модель при отсутствии интернета или блокировке облака.
