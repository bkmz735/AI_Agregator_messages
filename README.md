**AI Message Aggregator** — это современная, высокопроизводительная и полностью автономная система сбора, фильтрации, классификации и управления входящими сообщениями из различных источников (**VK**, **Mail.ru / Авито / Instagram**, **Telegram-каналы**).

Бот оснащен передовым ИИ-ассистентом на базе **Google Gemini (3.x / 2.5)** с поддержкой распознавания аудио/голосовых сообщений, вызова инструментов (Function Calling), веб-поиска Google Search, фильтрации спама, извлечения задолженностей/Госуслуг и автоматической очистки чатов.

---

## 🌟 Ключевые возможности

### 1. 📬 Агрегация из множества каналов
- **ВКонтакте (VK LongPoll)**: Мгновенное получение личных сообщений и сообщений групп, обработка текста, вложений и голосовых сообщений.
- **Mail.ru / Email (IMAP)**: Чтение почтовых ящиков по безопасному протоколу IMAP с поддержкой паролей приложений. Удобно для сбора уведомлений от Авито, маркетплейсов и сервисов.
- **Telegram News Channels**: Автоматический парсинг открытых публичных каналов через веб-интерфейс `t.me/s/` без необходимости авторизации под аккаунтом Telegram.

### 2. 🧠 Интеллектуальный AI-движок (Gemini 3.x / 2.5)
- **Каскадный перебор моделей с защитой от лимитов (Fallback & Cooldown)**:
  - Автоматический приоритет моделей (от высоколимитных `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite` до мощных `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-2.5-flash`).
  - Умное отслеживание лимитов 429 RPM/RPD: временное отключение отдельной модели при превышении минутного лимита и бесшовное переключение на следующую без задержек для пользователя.
- **Пакетная обработка сообщений (Token Saving)**: Сообщения группируются в пачки (чанги) и отправляются в ИИ одним запросом, снижая расход токенов до 80%.
- **Расшифровка голосовых сообщений**: Дословная транскрипция голосовых сообщений и аудиозаписей с последующей категоризацией и подготовкой черновика ответа.
- **Автоматическая классификация контента**:
  - `spam` (спам, реклама, казино, мошенники);
  - `urgent` (срочные сделки, клиенты, заказы);
  - `important` (важные личные и рабочие диалоги);
  - `gov_debt` / `gov_service` (штрафы, налоги, Госуслуги, повестки, суды);
  - `news` / `media` (новости, дайджесты, видеоролики);
  - `general` / `bullshit` (обычные сообщения и мусор).

### 3. 💬 Умный диалоговый ассистент (Conversational Agent)
- Общение с пользователем прямо в чате бота с сохранением контекста.
- Доступ к живому поиску информации в интернете через встроенный **Google Search**.
- Управление ботом на естественном языке с вызовом функций (**Function Calling**):
  - *«Добавь банворд "акция"»*
  - *«Найди и добавь канал Mash»*
  - *«Покажи статистику сообщений»*
  - *«Поставь часовой пояс Екатеринбург»*
  - *«Очисти историю чата»*

### 4. 🎛️ Гибкое интерактивное меню (Inline UI)
- **Режимы доставки**:
  - `⚡ СРАЗУ`: Мгновенная доставка входящих сообщений.
  - `📥 СВОДКА`: Сбор сообщений в буфер с периодической отправкой структурированного дайджеста.
- **Таймеры и интервалы**: Настройка интервала сводок (15м, 30м, 1ч, 2ч, 4ч) и часового пояса (UTC).
- **Часы тишины (Ночной режим)**: Остановка отправки и заморозка работы ИИ на ночь для экономии токенов и тишины.
- **Интерактивные фильтры категорий ИИ**: Включение/выключение категорий одной кнопкой (`🟢 Пропускать` / `🔴 Фильтровать`).
- **Строгие банворды**: Раздельные списки стоп-слов для Mail.ru и VK с удобной пагинацией и удалением.
- **Автоудаление сообщений**: Кнопки быстрого скрытия сообщений и настраиваемый таймер автоудаления прочитанных оповещений.

### 5. 🛡️ Стабильность и сетевые оптимизации
- **Xbox DNS Resolver**: Встроенный DNS-резолвер для стабильного доступа к серверам Google API в условиях сетевых ограничений.
- **Асинхронная архитектура**: Полностью неблокирующий ввод-вывод на базе `asyncio`, `aiogram 3.x` и `aiosqlite`.

## 🚀 Быстрый старт на Linux VPS

### 1. Клонирование и установка
```bash
git clone https://github.com/bkmz735/AI_Agregator_messages.git /opt/ai-message-aggregator
cd /opt/ai-message-aggregator
cp .env.example .env
nano .env
```

### 2. Настройка переменных в `.env`
Заполните обязательные параметры:
- `AI_API_KEY`: API ключ Google AI Studio (Gemini).
- `TELEGRAM_BOT_TOKEN`: Токен бота от [@BotFather](https://t.me/BotFather).
- `MASTER_CHAT_ID`: Ваш Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)).
- `VK_TOKEN` / `IMAP_USER` / `IMAP_PASSWORD`: Данные для подключения источников.

### 3. Автоматический запуск службы
```bash
chmod +x deploy.sh update.sh
./deploy.sh
```

Скрипт создаст виртуальное окружение, установит зависимости, настроит системную службу `systemd` и добавит удобные алиасы:
- `bot-update` — обновить бота из GitHub и перезапустить службу.
- `bot-logs` — открыть живой журнал работы бота.
- `bot-status` — проверить статус работы службы.
